# Pantry Tracker

Pantry Tracker is a responsive inventory management system built with React, Next.js, Firebase and Material-UI. It helps users efficiently manage and track over 200 pantry items with real-time updates and a powerful search feature.

---

## 🛠 Tech Stack

- React  
- Next.js  
- Firebase (Realtime Database & Authentication)  
- Material-UI  

---

##  Features

- Real-time inventory updates syncing across devices  
- Efficient search functionality for quick item retrieval  
- Responsive design for mobile and desktop  
- Manage over 200 pantry items easily
